# 😴 "মরবে না, শুধু ঘুমাবে" — এমন লিংক বানানোর গাইড

তুমি যেটা চাইছো সেটার টেকনিক্যাল নাম **sleep-on-idle hosting**:

- URL কখনো বদলায় না, কখনো "not found" দেখায় না
- কেউ ব্যবহার না করলে অ্যাপ **ঘুমিয়ে** যায় (ফ্রি রিসোর্স বাঁচে)
- কেউ লিংকে ঢুকলেই **নিজে থেকে জেগে ওঠে** (প্রথম লোডে ৩–১০ সেকেন্ড, তারপর স্বাভাবিক গতি)
- ডেটা (ইউজার, পোস্ট, ছবি) ঘুমের মধ্যেও **থেকে যায়**

আমার ওয়ার্কস্পেসের টানেল-লিংক এটা দিতে পারে না — ওগুলো ঘুমায় না, **মরে যায়**।
নিচের যেকোনো একটায় একবার বসালেই তুমি যেটা চাও ঠিক সেটাই পাবে।

## ⭐ অপশন ১ — Fly.io (সবচেয়ে ভালো মিল)

কনফিগ আমি আগেই লিখে দিয়েছি (`fly.toml`):

```toml
auto_stop_machines  = "stop"   # কেউ না থাকলে ঘুমাবে
auto_start_machines = true     # রিকোয়েস্ট এলে জাগবে
min_machines_running = 0
[[mounts]] source = "genzhub_data" destination = "/data"   # ডেটা কখনো হারাবে না
```

**ধাপ (মোট ~১০ মিনিট):**
```bash
unzip genz-hub-deploy.zip && cd genz-hub
npm i -g flyctl
fly auth signup                    # ← শুধু এই ধাপটা তোমার (ইমেইল + কার্ড ভেরিফিকেশন চাইতে পারে, চার্জ হবে না)
fly launch --no-deploy             # বান্ডিল করা fly.toml রাখবে
fly volumes create genzhub_data --size 3
fly secrets set ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='StrongPass123'
fly deploy
fly ssh console -C "npm run seed:demo"   # ডেমো ডেটা (ঐচ্ছিক)
```
ফল: **https://your-app.fly.dev** — চিরস্থায়ী, ঘুমায়-জাগে, ডেটা টেকে।

## অপশন ২ — Render.com (কার্ড লাগে না, কিন্তু ডেটা টেকে না)

- ফ্রি web service: URL চিরস্থায়ী, ১৫ মিনিট অলস থাকলে ঘুমায়, রিকোয়েস্টে জাগে (~৩০-৫০s প্রথম লোড)
- ⚠️ ফ্রি প্ল্যানে **ডিস্ক নেই** → রিস্টার্টে ডেটাবেজ রিসেট হয়ে ডেমো ডেটায় ফিরে যাবে
- শুধু **দেখানো/ডেমো** করার জন্য দারুণ; আসল ইউজারদের ডেটা রাখতে হলে ডিস্ক (পেইড, ~$7/মাস) বা Postgres লাগবে

```
GitHub-এ কোড পুশ করো → Render → New → Blueprint → render.yaml সিলেক্ট → Deploy
```
